# palaeo-p4

**Matt Wedel <mathew.wedel@gmail.com>**  
**Mike Taylor <dino@miketaylor.org.uk>**  

This repository contains work on an ongoing paper about two newly recognised osteological features of some sauropod vertebrae, which we term the pre-postepipophysis (PRPOE) and post-preepipophysis (POPRE).
